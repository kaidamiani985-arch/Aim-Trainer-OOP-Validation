# Aim Trainer

A reflex and reaction-time game built with Python and tkinter.

<img src="https://github.com/user-attachments/assets/55fbe979-b9ba-426c-acab-f97a3d8c56de" alt="Aim Trainer screenshot" width="600">

## How it works

Multiple target shapes (circles, squares, triangles, octagons) appear at random positions.
The spawn rate gradually increases, so click the shapes as fast as you can to score points.

Requires Python 3 with tkinter.
