
## Aim Trainer is a reflex and reaction‑time game built with Python and tkinter.
--- 
<img width="1000" height="894" alt="Screenshot 2026-08-03 at 10 40 35 pm" src="https://github.com/user-attachments/assets/55fbe979-b9ba-426c-acab-f97a3d8c56de" />

---

Multiple target shapes (circles, squares, triangles, octagons) appear at random positions. As the spawn rate gradually increase, click shapes as quickly as possible to score points.


Run it with: python "Aim Trainer.py"

Requires Python 3 with tkinter.
